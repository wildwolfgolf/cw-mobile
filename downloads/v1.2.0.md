## Русский

Добавлен профиль **Yaesu FT-891** с CAT по USB Enhanced, настройкой частоты и режима, переключением SPLIT и передачей через внешний аудиоинтерфейс на заднем RTTY/DATA. Для TX выберите DATA, 08-09 = REAR и 08-12 = USB. Подробности — в [инструкции подключения](https://github.com/wildwolfgolf/cw-mobile/blob/main/docs/connection-ru.md#yaesu-ft-891).

Профиль проверен на имитаторе CAT. USB-аудио и передача на физическом FT-891 требуют аппаратной проверки. APK подписан новым тестовым ключом. При переходе с APK 1.1.0 сохраните важные настройки вручную перед удалением старого приложения.

## English

Adds **Yaesu FT-891** support for CAT via USB Enhanced, frequency and mode control, split operation, and audio transmission through an external interface connected to the rear RTTY/DATA jack. For TX, select DATA with menu 08-09 set to REAR and 08-12 set to USB.

The profile was tested against simulated CAT responses. USB audio and RF transmission still need hardware validation. The APK uses a new debug signing key. Before uninstalling 1.1.0 to install this build, save any settings you need to keep.
