# Подключение и настройка

В **Оборудование** задайте модель, скорость CAT, формат линии, USB-порт и аудиоустройства. На FT-991A и FT-891 используйте порт Enhanced, если Android показывает два последовательных интерфейса. **Автоматически** выбирает порт, когда найден один кандидат. Для нескольких устройств укажите нужный порт вручную. Сохраните настройки, нажмите **Подключить CAT** и убедитесь, что приложение читает текущую частоту. **Телеметрия** содержит журнал запросов CAT.

| Модель | Что настроить на трансивере |
| --- | --- |
| Xiegu G90 | DE-19 ACC → задний ACC, CIV → COMM на головке, USB DE-19 → Android. Для аудио используйте U-D. При необходимости проверьте другой CAT-порт и адрес `88` вместо `70`. |
| Icom IC-7300 | USB на задней панели. Сверьте меню CI-V USB Baud Rate, адрес `94`, выберите USB-D, DATA MOD = USB. Для спокойного опроса можно выключить CI-V Transceive. |
| Yaesu FT-991A | USB на задней панели, порт Enhanced. Скорость приложения должна совпадать с CAT RATE. При выключенном CAT RTS оставьте RTS/CTS выключенным и в приложении. Для TX задайте DATA-USB, меню 070 DATA IN SELECT = REAR и меню 072 DATA PORT SELECT = USB. |
| Yaesu FT-891 | USB Enhanced для CAT, 4800 8N2. Сверьте меню 05-06 CAT RATE и 05-08 CAT RTS. Аудио через внешний USB-интерфейс на задний RTTY/DATA. Для TX выберите DATA, 08-09 = REAR, 08-12 = USB. |
| Kenwood TS-590SG | USB маркировки «USB». Сверьте меню 68 USB Port Communication Speed. Задайте USB-DATA и меню 69 DATA Modulation Line = USB. Уровень USB-входа и выхода настраивается меню 71/72. Для TX профиль отправляет `TX1;` и возвращает RX командой `RX;`. |
| Wolf 2 | USB CAT/CW, Calibration → Control → CAT Type = TS-2000. Назначьте DTR = CW/Keyer и RTS = PTT. Используйте CW или CWR, отключите XIT и SPLIT. Для TX не выбирается аудиовыход. |

## Yaesu FT-891

1. Подключите USB-порт FT-891 к Android через OTG. В **Оборудовании** выберите профиль **Yaesu FT-891** и порт **Enhanced**. Начальное значение 4800 бод соответствует заводской настройке 05-06. При **05-08 CAT RTS = ENABLE** включите **RTS/CTS для CAT**. Если этот пункт на трансивере выключен, снимите флажок в приложении.
2. Для проводного приёма и передачи звука используйте внешний USB-аудиоинтерфейс для цифровых режимов и кабель к заднему **RTTY/DATA**. USB‑порт самого FT‑891 предоставляет CAT, а аудио выбирается в приложении отдельно. При двух USB-устройствах используйте совместимый OTG-хаб. Для приёма также можно выбрать микрофон телефона.
3. Для TX выберите **DATA** на трансивере, **08-09 DATA IN SELECT = REAR** и **08-12 DATA BFO = USB**. Выберите аудиовыход внешнего интерфейса. Приложение включает PTT по CAT и проверяет оба пункта меню перед передачей. На первой пробе используйте эквивалент нагрузки и малую мощность.

На приёме начните с 700 Гц, 18 WPM, −34 дБFS и 200 Гц. Подстройте трансивер под тон декодера. Фильтр можно переключать во время приёма. Для изменения тона, алфавита, стартовой WPM и порога перезапустите RX. Кнопки диапазонов переключают частоту. Ввод частоты выполнен в герцах. Доступные операции VFO зависят от профиля.

| Симптом | Действие |
| --- | --- |
| Нет CAT-порта | Проверьте поддержку OTG, кабель данных и питание USB. Если модель даёт несколько COM-портов, попробуйте правильный интерфейс через **Оборудование**. |
| CAT-порт есть, но нет частоты | Сверьте профиль, скорость, 8N1/8N2, RTS/CTS и CI-V-адрес. Закройте другое приложение, использующее порт. |
| CAT работает, RX молчит | Выберите USB-аудиовход или встроенный микрофон, разрешите доступ к аудио. Проверьте уровень выхода USB/ACC на трансивере. |
| Передача останавливается при проверке | Выставьте режим из таблицы, выключите SPLIT и проверьте источник звука. Wolf 2 должен подтверждать TX по CAT после включения RTS. |
| PTT срабатывает, RF отсутствует | Проверьте USB-аудиовыход, уровни и аппаратные настройки источника. Для Wolf 2 проверьте назначение DTR. |
| Возврат в RX не подтверждён | Проверьте индикацию на панели трансивера. При обрыве физического подключения приложение может потерять возможность снять PTT. |

На TX часть телеметрии зависит от команды и прошивки. У G90 и IC-7300 КСВ выводится по калибровке CI-V, у остальных моделей показания CAT могут отображаться в родной шкале. Текущая версия Wolf 2 делает запросы состояния перед ключеванием и после него, чтобы опрос USB не нарушал длительность точек и тире.
